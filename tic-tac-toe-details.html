TIC TAC TOE - Project Details

Project Overview

A classic Tic Tac Toe game built with HTML, CSS, and JavaScript. This project allows you to play against the computer or another player in a classic grid layout. The game includes win conditions, player turns, and a reset functionality.

Technologies Used:

  • HTML
  • CSS
  • JavaScript

Project Features:

  • 2-player mode
  • Computer opponent
  • Dynamic score tracking
