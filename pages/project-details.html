Interactive Dashboard - Project Details

About the Project

This project is an interactive Excel dashboard showcasing billionaires around the world. It features dynamic filtering capabilities, allowing users to filter data based on various criteria such as country, industry, and wealth.

Key Features

  • Interactive filtering options
  • Real-time data updates
  • User-friendly interface
  • Customizable views

Technologies Used

  • Excel
  • VBA (Visual Basic for Applications)
  • Power Query for Data Integration

How It Works

The dashboard pulls data from various sources and presents it in an interactive format. Users can filter the data based on various parameters such as net worth, industry, and country. The dashboard is designed to be intuitive and easy to navigate.
