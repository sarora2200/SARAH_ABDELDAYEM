Sales Dashboard - Project Details

About the Project

This project is an interactive Excel dashboard designed to track and analyze sales performance. It features dynamic filtering capabilities, allowing users to drill down into data by product, region, and time period.

Key Features

  • Dynamic filtering for detailed analysis
  • Visual representation of sales trends
  • Top-performing products and regions overview
  • Customizable date ranges

Technologies Used

  • Excel
  • VBA (Visual Basic for Applications)
  • Power Query for Data Integration

How It Works

The dashboard consolidates sales data from multiple sources and presents it in an interactive format. Users can filter the data by product, region, or time period to gain insights into performance trends and top-selling items.
